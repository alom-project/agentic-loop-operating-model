# ALOM

AI × Human Production Operating Architecture

ALOM defines a seven-layer operating architecture for managing work and production performed by humans and AI agents. It operates purpose, authority, context, structure, execution, evaluation, knowledge, evidence, control, stop / remedy, and learning through consistent responsibility boundaries.

## Applying Organization

An applying organization can be a business, public body, educational or research institution, nonprofit, or another type of organization. Enterprise is the scope of the applying organization as a whole; it is distinct from the optional Organization overlay. The template's `enterprise_id` is an existing identifier name, and `company` is an illustrative value.
